# Core functionality

Feature checklist with pointers to the modules that implement and test each one. `[x]` = implemented and verified in this audit (by code reading and `npm run verify`: 17/17 tests pass); `[ ]` = not implemented / known gap.

See also: [architecture](architecture.md) · [user flows](user-flows.md) · [audit findings](audit.md)

## Language support

- [x] `.rw` files recognised as language `risingwave-sql` (aliases `rw`, `risingwave`): `package.json` → `contributes.languages`
- [x] Line comments `--`, block comments `/* */`, bracket matching, auto-close `{ [ ( " '` (not inside strings; `'` also not inside comments): `language-configuration.json`
- [x] Lazy activation only when a RisingWave file is opened: `package.json` → `activationEvents`
- [x] Editor defaults for `[risingwave-sql]`: `package.json` → `configurationDefaults`
- [ ] Format on save, linting, SQL validation, or connection to a RisingWave instance (not planned; no language server)

## Syntax highlighting

Module: `syntaxes/risingwave.tmLanguage.json` (regexes generated by `scripts/build.js` from `data/risingwave.json`). Tests: `test/grammar.test.js`.

- [x] RisingWave DDL: `CREATE/ALTER/DROP SOURCE | SINK | MATERIALIZED VIEW`
- [x] Streaming keywords: `EMIT ON WINDOW CLOSE`, `EMIT ON UPDATE`, `EMIT IMMEDIATELY`, `WATERMARK FOR`, `ASOF [LEFT] JOIN`, `TEMPORAL JOIN`, `INCLUDE KEY | TIMESTAMP | PARTITION | OFFSET | HEADER`
- [x] Window functions: `TUMBLE`, `HOP`, `SESSION` and their `_START` / `_END` variants
- [x] Admin commands: `SHOW SOURCES | SINKS | MATERIALIZED VIEWS | JOBS | …`, `CANCEL JOB(S)`, `FLUSH`, `PAUSE`, `RESUME`, …
- [x] `FORMAT <fmt>` and `ENCODE <enc>` value highlighting; bare `FORMAT` / `ENCODE`
- [x] `WITH ( … )` and `ENCODE x ( … )` option blocks: known option keys, `connector = '<name>'` value, arbitrary dotted keys as parameters
- [x] RisingWave types and `proctime`
- [x] PostgreSQL keywords (DML, DDL, transactions), types, functions (aggregate, string, date/time, JSON, window), operators, numbers
- [x] Strings (single, double, `$$` dollar-quoted) and comments suppress keyword matching inside them
- [x] Context-sensitivity: `JSON` is a PostgreSQL type unless after `ENCODE`; `type`/`connector`/… are option keys only inside option blocks
- [ ] Semantic tokens (e.g. distinguishing column vs table names); all identifiers get the same scope
- [ ] Highlighting for `.sql` files from RisingWave scopes (by design `.sql` gets snippets only)

## Hover documentation

Modules: `extension.js` (`getWordAtPosition`, `createHoverContent`, hover provider), `lib/keywords.js` (`findCompoundKeywordAt`, `findDoc`, `risingwaveKeywordDocs`). Tests: `test/keywords.test.js`.

- [x] 26 documented items: `CREATE SOURCE/SINK/MATERIALIZED VIEW`, `TUMBLE`/`HOP`/`SESSION` (+ start/end), `EMIT ON WINDOW CLOSE`, `WATERMARK`, `ASOF JOIN`, `ASOF LEFT JOIN`, `TEMPORAL JOIN`, `INCLUDE KEY/TIMESTAMP`, `proctime`, `FORMAT`, `ENCODE`, and connectors `kafka`, `postgres-cdc`, `sqlserver-cdc`, `mongodb`, `snowflake`, `jdbc`
- [x] Compound keywords matched longest-first, tolerant of any whitespace between words
- [x] Hover only fires when the cursor is inside the keyword span; range covers the whole keyword
- [x] Case-insensitive lookup
- [x] Sections: description, syntax, parameters, example, docs link
- [ ] Hover for compound keywords split across lines (see [audit](audit.md#known-limitations))
- [ ] Docs for every keyword: 26 entries exist; admin commands, most connectors, `INCLUDE PARTITION/OFFSET/HEADER` have none

## Completion

Modules: `extension.js` (completion provider), `lib/keywords.js` (`completionLists`). Test: `completion lists are non-empty and deduplicated`.

- [x] Connector names (all unique names from sources and sinks)
- [x] Formats and encodings
- [x] Window and streaming keywords, RisingWave functions
- [x] Attached documentation when a `docs` entry exists
- [x] Trigger characters `'` and `=`
- [ ] Context-aware suggestions (e.g. connectors only in `connector = '…'`, option keys per connector)
- [ ] DDL / admin keywords in completion (snippets cover most of these)

## Snippets

Modules: `snippets/risingwave.json` (27 snippets), `snippets/postgres.json` (7), `snippets/misc.json` (1). Registered in `package.json` → `contributes.snippets`. Tables are generated into [README](../README.md).

- [x] Materialized views: `mv`, `mvwindow`
- [x] Sources: Kafka, Kafka upsert, PostgreSQL CDC, SQL Server CDC, MySQL CDC, Debezium via Kafka, datagen
- [x] Sinks: MongoDB, PostgreSQL (JDBC), SQL Server (JDBC), Kafka, Snowflake
- [x] Windows / joins / watermarks: `tumble`, `hop`, `emitclose`, `asof`, `temporaljoin`, `watermark`
- [x] Utility: `proctime`, `computed`, `showsources`, `showsinks`, `showmv`, `desc`, `explain`
- [x] PostgreSQL: `table`, `insert`, `upsert`, `index`, `fk`, `func`, `win`; standard file header `header`
- [x] PostgreSQL + misc snippets also available in plain `.sql`
- [ ] Snippets for connectors without one: MongoDB CDC, Kinesis, Pulsar, S3/GCS/Azure Blob, Nexmark, ClickHouse, Doris, StarRocks, Iceberg, Delta, Redis, Elasticsearch
